# 发音词典（示例模板）
#
# 作用：人名、地名、专有名词被读错时，在这里告诉朗读器"读成什么"。
# 一行一条：「原词 = 替换」，# 开头的行和行内 # 后面是注释。
#
# 中文：直接写同音字或希望的写法
# 菲洛米娜 = 飞罗米娜
#
# 英文名用重拼（怎么读就怎么拼）
# Kvothe = Quothe
#
# 带 * 表示前缀通配：迷雾之子* 会同时命中「迷雾之子的」等所有以它开头的组合
# （中文没有词界，加不加 * 效果一样，两种写法都支持）
#
# 生效范围：
#   本文件（项目根目录 pronounce.txt）= 所有书全局生效
#   与书同名同目录的 <书名>.pronounce.txt = 只对那本书生效，
#   同名词条会覆盖本文件的词条。
#
# 词条改动后，该书的断点指纹会变化，重新拖入会从头合成（这是预期行为：
# 文本改了，音频必须重念）。
#
# 删除/注释掉所有行 = 不做任何替换。
